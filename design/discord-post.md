## Logline
A 2D top-down maze game where the maze itself is lying to you: hidden walls, walls that move and vanish, floors that collapse, triggers that rewire the layout, a fake goal, and a shadow that hunts your trail. Every layout is guaranteed solvable and every lie follows a learnable rule, so dying and trying again (on the exact same layout) turns memory into the real skill.

## Description
Race from Start to Destination through a maze that grows by one cell in every dimension each level. From level 2 on, new kinds of deceptive or reactive obstacles unlock on a fixed schedule: invisible walls (paired with a tile that briefly reveals them), sliding and disappearing walls, collapsing floors, color-linked trigger plates, teleporters, rotating gates, patrols, one-way corridors, a decoy destination, and finally a chaser that follows your own trail. Dying restarts the current attempt on the identical layout, so every trap you learn stays learned.

## Controls
- WASD / Arrow keys: move (grid steps, hold to keep moving)
- Space / Enter: start the game, or skip the intro card
- R: restart the current attempt
- P / Esc: pause
- M: mute
- F2: toggle the demo autopilot
